Agents and access

Every invite, member revocation, permission grant, and certificate change on this page applies only to this project.

Members are enrolled separately in each project. Network clients must present this project’s member credential; TLS clients on the LAN or remotely also need a certificate grant for this same project.

This invitation grants access to the currently selected project only. It downloads a private project credential. For a TLS client on the LAN or remotely, add its certificate here to grant project membership and certificate access atomically; otherwise grant the certificate separately in this project.

Action permissions

Worker and Reviewer enrollment creates a one-time starter grant set. Every action requires project.read plus its matching action grant. membership.manage can enroll or revoke workers and reviewers; owner creation and TLS certificate grants remain owner-only. Grants stay independent after enrollment: changing work duties never changes permissions. Each grant applies only to this project and can be revoked here.
